# مدار · علوم السادس الابتدائي

كتاب تفاعلي لصفحات كتاب العلوم للصف السادس الابتدائي **٦٢–٦٩**: الدرس الثاني (الجهاز الهيكلي) والدرس الثالث (الجهاز العضلي).

- يُعرض على الموبايل بالعرض، وتُقلَّب صفحاته كالكتاب.
- نص الكتاب كما هو، مع قراءة صوتية وشرح من شخصية «عضلون».
- ألعاب سحب وإفلات، وجسم عضلي متحرك، ومختبر أنموذج العضلة (ص ٦٧).

الصفحة كلها في ملف واحد: `index.html`.
